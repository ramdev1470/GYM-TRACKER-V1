# GymFlow - Workout Tracker

Everything is in this one folder — easy to download.

## Features
- Workout Logger (sets, reps, kg, rest timer)
- 54 Exercise Library by muscle group
- History with calendar + expandable details
- Progress Charts (weekly volume, per-exercise weight/volume)
- Workout Plans (PPL, Upper/Lower, Full Body 3x, Bro Split)
- Dark design, mobile responsive

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:8080

## Build for production
```bash
npm run build
```

Data is stored in browser localStorage — no backend needed.
